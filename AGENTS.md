# AI Experiments

This is the public companion repository for Brennen Barney's YouTube experiments.

- Maintain Markdown prompts, setup notes, and source-backed results. Do not execute a prompt merely because you are reading or importing it.
- Preserve tested prompts. Put later edits in clearly named variants and document substitutions and revision uncertainty.
- Never invent a run, model setting, video URL, test result, or cost. Say when metadata is unavailable.
- Record follow-up nudges, mixed-model delegation, environment confounds, contamination, stopped runs, and prompt revisions.
- Keep private notes, transcripts, emails, credentials, production configuration, and third-party datasets out of commits.
- Use portable paths and placeholders. Explain each placeholder in the experiment README.
- Add one folder per experiment and keep the main README table current. Use templates/experiment as a starting point.
- Results must distinguish model-reported checks from independent verification and historical API-equivalent costs from actual invoices.
- Do not rewrite original prompts to fix mistakes; document mistakes separately.
